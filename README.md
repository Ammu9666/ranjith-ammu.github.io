## Publish on GitHub Pages
1. Create a GitHub repository named `ranjith-ammu.github.io`.
2. Upload `index.html`, `style.css`, `Ranjith_Ammu_Resume.pdf`, and this README.
3. Open Settings → Pages.
4. Select Deploy from branch → main → root.
5. Save. GitHub will provide your public portfolio URL.
